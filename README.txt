HAVTEK WEBSITE: plain HTML, CSS and JavaScript
==============================================

Files
  index.html        the whole site (Home, Services, About, Process, Pricing, FAQ, Contact, Privacy, Terms)
  style.css         all styles
  script.js         all behaviour (page switching, animations, robot hero, form)
  images/           the photos and illustrations
  vendor/three.min.js   three.js r128 (used by the robot hero and the process background)
  favicon.svg, robots.txt

Open it
  Double-click index.html to preview locally, or drag the whole folder onto Netlify,
  Cloudflare Pages, or upload it to GitHub Pages / any web host (cPanel public_html).

Contact form
  It currently opens the visitor's email app (mailto). To receive messages directly,
  use a form service (Formspree or Netlify Forms) and point the form at it.

How pages work
  Pages switch inside index.html (addresses look like  yourdomain.com/#pricing).
  The back button works. If you later want separate real pages (pricing.html etc.) for
  better Google results, that is a straightforward split.
